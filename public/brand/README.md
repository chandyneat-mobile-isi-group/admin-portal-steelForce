# public/brand — generated

Do not edit these files by hand. They are built from the masters in `assets/`:

```
npm run brand:build
```

Anything you change here is overwritten on the next build. To change a brand
asset, change it in `assets/` and rebuild. See `assets/README.md`.

Paths are exported from `src/lib/brand/assets.ts` — import from there rather
than writing `/brand/...` strings at call sites.
